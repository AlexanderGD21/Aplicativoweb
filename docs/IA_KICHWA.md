# IA para Kichwa Unificado

La IA está desactivada por defecto y ninguna clave llega al navegador. El único
contrato inicial permitido es `vits_http`, para un servicio privado propio.

Para pronunciación, prioriza audio humano revisado y consentido. Un modelo VITS
debe entrenarse con corpus autorizado, una guía ortográfica/G2P para Kichwa
Unificado y evaluación de hablantes. No publiques voz sintética sin revisión
lingüística humana.
